# 司法書士 独学ドリル

2027年（令和9年度）司法書士試験（筆記試験 2027年7月4日・予測）に向けた独学用のPWAです。`index.html` をブラウザで開くだけで使えます。GitHub Pagesで公開すれば、スマートフォンのホーム画面に追加できます。

## 収録内容

- ホーム：試験までの日数、今週の目標、今日の学習時間の記録（＋0.5h〜3h）、今後の予定
- ○×問題：オリジナル問題（科目別・順番／ランダム／苦手／未回答、2回連続正解で「覚えた」）
- 比較表：制限行為能力者、意思表示の瑕疵、担保物権、保証、時効、登記の申請形態、役員の任期、株主総会の決議要件など
- 計画：33週の週間計画（完了チェック、週ごとの学習時間）
- 記録：累計学習時間、科目別の正答率

学習計画・問題・比較表は `../司法書士2027_学習計画.xlsx` と同じ内容です。問題はすべてオリジナルです。日程は予測のため、法務省の公式発表で確認してください。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作ります（例：`shiho-study`、Public）。賃貸管理士アプリとは別のリポジトリにしてください。
2. 「uploading an existing file」から、`index.html`・`manifest.json`・`sw.js`・`icon-192.png`・`icon-512.png` の5つをアップロードします。
3. **Settings > Pages** で、Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save します。
4. 表示されたURLをスマートフォンで開き、ホーム画面に追加します（iPhone：Safariの共有→ホーム画面に追加）。

更新するときは `index.html` と `sw.js` を上書きアップロードします。学習記録は消えません。

## データの取り扱い

学習記録（○×の正誤・週の完了・学習時間）は端末のブラウザ内（localStorage）にだけ保存され、外部には送信されません。

## 元データ

`../_source` に元データと生成スクリプトがあります（GitHubにはアップロードしないでください）。
`node gen_app.js ../アプリ/index.html` でアプリを、`node build_xlsx.js ../司法書士2027_学習計画.xlsx` でExcelを生成します（exceljs が必要）。
