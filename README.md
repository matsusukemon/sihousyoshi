# 買取再販 実践マニュアル

区分マンション・アパート一室の買取再販業務を、新人でも再現性高く進めるための実務マニュアル兼管理アプリです。`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで動作します。インストールやネット接続は不要です。

## GitHub Pagesで公開（Gitのインストール不要）

1. GitHubにログインし、右上の「＋」→「New repository」で新しいリポジトリを作成します（例：`kaitori-saihan`）。**Public** を選び、他の項目はそのままで「Create repository」を押します。
2. 作成直後の画面で「uploading an existing file」をクリックし、このフォルダー内の次の6ファイルをまとめてドラッグ＆ドロップして「Commit changes」を押します。
   `index.html` / `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png` / `README.md`
3. リポジトリの **Settings → Pages** を開き、「Source」を **Deploy from a branch**、ブランチを **main**・フォルダーを **/(root)** にして「Save」を押します。
4. 1〜2分待ってページを再読み込みすると、上部に公開URL（`https://ユーザー名.github.io/kaitori-saihan/`）が表示されます。

アプリを修正したときは、同じ「Add file → Upload files」で上書きアップロードすれば数分で反映されます。

## スマートフォンに追加

- iPhone：Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」。
- Android：Chromeで公開URLを開き、メニュー →「アプリをインストール」または「ホーム画面に追加」。

## 買取価格シミュレーターの計算式

想定再販価格 − リフォーム費 − 取得費 − 保有費 − 販売費 − 安全余裕 − 目標利益 ＝ 買取上限価格

- 仕入れ時の仲介手数料と借入金利は買取価格によって変わるため、上限価格は反復計算で求めています。
- 仲介手数料は宅建業法の上限額（400万円超は「価格×3%＋6万円」＋消費税）で計算しています。
- 目標利益は「再販価格×目標利益率」と「最低確保利益」の大きいほうを採用します。
- 初期値（取得費・保有費・リフォーム単価など）は目安です。自社の実績値に合わせて変更してください。

## データの保存

- 入力内容はブラウザ内（localStorage）に自動保存されます。別のブラウザや端末とは共有されません。
- ブラウザの閲覧データを削除すると消えるため、画面上部の「バックアップ」で定期的にJSONファイルを保存してください。「復元」で読み込めます。
- バックアップファイルには物件情報や取引先情報が含まれます。取り扱いに注意してください。
- 公開されるのはアプリのプログラムだけで、入力したデータは各端末の中にのみ保存され、インターネット上には送信されません。バックアップのJSONファイルはリポジトリにアップロードしないでください。
- パソコンとスマホ、またSafariとホーム画面のアプリでは保存場所が別になります。データを移すときは「バックアップ」→「復元」を使ってください。
